## Project Summary
NEXUS is a web-based multi-agent productivity platform that brings task management, notes, calendar scheduling, weather information, knowledge storage, and command routing into a single interface.

## Agents
1. Task Agent
2. Notes Agent
3. Calendar Agent
4. Knowledge Agent
5. Weather Agent
6. Router Agent

- HTML
- CSS
- JavaScript

Backend:
- Python 3.11
- FastAPI
- Uvicorn
- Pydantic

Infrastructure:
- Docker

## Local Setup
```bash
pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

Open `http://127.0.0.1:8000`.
