## Project

**PlacementPilot — Agentic Career Preparation Assistant**

PlacementPilot is a stateless, multi-agent AI application designed to help students analyse a target placement role, identify skill gaps, practise role-specific questions, and prepare for mock interviews.

The application uses a guided single-page workflow covering:

- Resume intelligence
- Target role analysis
- Placement analytics
- Skill-gap identification
- Interview preparation
- Role-specific mock testing
- Answer evaluation
- Mock interview
- Agent execution monitoring
