# PlacementPilot design skill application

This project applies the public Taste Skill guidance from Leonxlnx/taste-skill to an existing product UI: audit-first redesign, strong hierarchy, restrained one-accent palette, intentional asymmetric composition, no generic AI-purple treatment, real loading/error/empty states, and motion used for hierarchy rather than decoration.

Design dials for PlacementPilot: DESIGN_VARIANCE 8 / MOTION_INTENSITY 9 / VISUAL_DENSITY 6.

Upstream skill: https://github.com/Leonxlnx/taste-skill
