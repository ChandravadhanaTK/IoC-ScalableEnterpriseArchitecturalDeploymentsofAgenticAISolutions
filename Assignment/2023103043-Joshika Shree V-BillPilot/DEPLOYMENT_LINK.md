# BillPilot AI — Deployment Link

**Live application:** https://cuddly-connect-app.lovable.app

The public landing page is hosted on Lovable. Authenticated workflows require a configured account and backend environment. The app uses Supabase for authentication/persistence and Lovable AI gateway for server-side AI features.

See [SourceCode/README.md](SourceCode/README.md) and [SourceCode/.env.example](SourceCode/.env.example) for local setup. Configure Supabase, apply migrations, and set environment values in hosting. The private source `.env` is intentionally excluded.
