# Taskora — Student Productivity Hub

A centralized productivity platform designed to help students organize academic tasks, plan study activities, manage notes, and track their progress.

**Live Demo:** [Taskora](https://sharp-look-tool.lovable.app/)

## Overview

Taskora brings essential student productivity tools into one workspace. It provides an interface for managing tasks, organizing study schedules, maintaining notes, and monitoring productivity.

## Features

* **Dashboard:** View an overview of tasks and productivity.
* **Task Management:** Organize and manage academic responsibilities.
* **Study Planner:** Structure study schedules and activities.
* **Focus Workspace:** Support focused study sessions.
* **Notes Management:** Keep study-related notes organized.
* **Productivity Analytics:** Review task progress and productivity information.
* **Authentication:** Login, registration, and password recovery interfaces.
* **Profile Management:** Access profile-related information.

## Getting Started

### Prerequisites

* Node.js
* npm

### Installation

1. Clone or download this repository.
2. Navigate to the Taskora project directory.
3. Install dependencies:

```bash
npm install
```

4. Configure the required environment variables and backend services.
5. Start the development server:

```bash
npm run dev
```

Open the local URL displayed in the terminal.

## Configuration

Configure the environment variables required by the application and its Supabase integration. Do not commit API secrets, private keys, or other sensitive credentials to the repository.
