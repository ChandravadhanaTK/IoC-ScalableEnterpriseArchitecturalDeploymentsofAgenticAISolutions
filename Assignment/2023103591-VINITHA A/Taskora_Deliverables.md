# Taskora — Project Deliverables

## 1. Project Overview

**Project Name:** Taskora — Student Productivity Hub

**Live Application:** [Taskora](https://sharp-look-tool.lovable.app/)

## 2. Project Objective

Taskora is a student productivity platform designed to help students organize academic tasks, plan study activities, manage notes, track deadlines, and monitor productivity through a centralized workspace.

## 3. Key Features

* **Dashboard:** Overview of tasks and productivity.
* **Task Management:** Organize and manage academic tasks.
* **Study Planner:** Plan study schedules and academic activities.
* **Focus Workspace:** Support focused study sessions.
* **Notes Management:** Organize study-related notes.
* **Analytics:** Track task progress and productivity.
* **Authentication:** Login, registration, and password recovery interfaces.
* **Profile Management:** Access profile-related information.

## 4. Technology Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Supabase integration
