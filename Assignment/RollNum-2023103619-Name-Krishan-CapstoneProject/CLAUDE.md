## Git Rules

**Feature branches — mandatory:** Every new feature must be developed on its own branch and delivered as a pull request. Never commit new features directly to `main`.

1. Create a branch: `git checkout -b feature/<short-name>`
2. Implement and commit the feature on that branch.
3. Push the branch and open a PR: `gh pr create`
4. Do **not** merge the PR yourself — leave it for the user to review and merge.
