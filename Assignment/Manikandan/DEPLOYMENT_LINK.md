## Local Application Access & Run Instructions

```bash
# Navigate to SourceCode directory
cd SourceCode

# Install backend dependencies
cd backend && npm install && cd ..

# Install frontend dependencies
cd frontend && npm install && cd ..

# Launch full-stack platform (runs backend on :5000 & frontend on :3000)
node start.js
```

Navigate to `http://localhost:3000` to access the interactive Agentic AI Dashboard.

## Description

The **Enterprise Agentic Orchestration Platform** is an enterprise-grade multi-agent AI system featuring autonomous task decomposition, tool execution (JS Code Sandbox, Web Search, DB Query), safety guardrails (PII scrubbing, Prompt Injection shielding), Human-in-the-Loop (HITL) risk management, and real-time telemetry (latency, token usage, cost audit).
