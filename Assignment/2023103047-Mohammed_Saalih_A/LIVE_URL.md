# Stonks Fish — Live Application

## Live URL

https://stonks-fish-chess-tutor.lovable.app/

## Application

**STONKS FISH — Your AI Chess Coach**

The live application currently provides a Game Analyzer experience where users can paste a chess game and have the coach walk through the game using chess ideas rather than engine numbers.

## Purpose

Stonks Fish is designed as an agentic AI chess tutor focused on:

- PGN game analysis
- Human-readable move explanations
- Opening training
- Defense training
- Interactive chess questions
- Adaptive coaching
- Long-term improvement
