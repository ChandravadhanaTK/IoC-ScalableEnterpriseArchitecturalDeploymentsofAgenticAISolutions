# Submission Structure

Place this complete folder inside your Roll Number - Name folder.

```text
RollNum-XXXX-Name-YourName/
├── prompt.md
├── deliverables.md
├── README.md
├── SUBMISSION_STRUCTURE.md
├── .gitignore
├── .env.example
├── agents/
├── backend/
├── frontend/
└── docs/
```

Do not upload `.env` or `node_modules`.
