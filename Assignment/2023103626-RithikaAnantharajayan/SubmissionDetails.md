## Project Description

PlantCare AI is an AI-powered agentic plant-care assistant that helps users manage their plants, track care activities, generate personalized care plans, and receive AI-powered recommendations.

## Technology Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Firebase Authentication
* Cloud Firestore
* Gemini AI
* Firebase Hosting

## Application Features

* User authentication
* Plant management
* Plant-care task tracking
* Care history
* AI-powered plant-care assistant
* Personalized care plans
* Vacation care planning
* Agentic AI workflow
* Human confirmation for important data modifications
* Monitoring dashboard
