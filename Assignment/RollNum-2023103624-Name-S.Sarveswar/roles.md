# AI Financial Assistant — User Roles

## 1. User

### Permissions

- Login and logout
- View personal dashboard
- View personal transactions
- Upload transaction data
- View personal fraud alerts
- View personal financial analysis
- Generate financial reports
- Ask AI Financial Assistant questions
- View personal profile

---

## 2. Financial Analyst

### Permissions

- View financial data
- Analyze transactions
- Review financial insights
- Review fraud alerts
- Generate financial reports
- View analytics dashboard
- Review flagged transactions
- Review financial trends

---

## 3. Administrator

### Permissions

- Manage users
- Manage user roles
- View system dashboard
- View transactions
- View fraud alerts
- View financial analytics
- Generate reports
- View system activity
- View audit logs
- Manage application settings

---
